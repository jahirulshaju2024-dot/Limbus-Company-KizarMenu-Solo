## 🌒 Overview

**Limbus Ledger** is a thematically-driven companion suite for solo play in *Limbus Company*. It borrows the sharp red-and-black attitude of Kizar styling and reshapes it into a utility dashboard: a modular overlay that quietly sits beside your run, offering combat comfort, stat transparency, and quality-of-life refinements — without breaking the brooding atmosphere of the City.

Where other tools shout, Limbus Ledger whispers. It is not a shortcut past the story. It is a lantern in the fog: better visibility, smoother turns, and a hand on the shoulder when the RNG of the Mirror Dungeon grows teeth.

The project is engineered with the same philosophy as a well-tuned rapier — elegant in motion, precise under pressure, and utterly useless in clumsy hands. Every toggle is deliberate. Every panel is intentional. Nothing ships unless it feels like it belongs in the world of Limbus Company.

## 🧠 Design Philosophy

Limbus Ledger was built on three beliefs:

1. **Comfort is not cheating.** A player who can see their own stats clearly makes better decisions. That is not power — that is literacy.
2. **The mood is sacred.** The City is grim, gorgeous, and meticulously composed. A tool that breaks that mood is a tool that fails. Every panel uses the same palette, the same weight, the same restraint.
3. **Solo means solo.** No leaderboards. No telemetry phoning home. No social pressure. Your run is yours.

The name "Ledger" comes from the idea that every run is a record — of choices, of luck, of learning. This tool simply helps you keep better books.

---

## 🖥️ Responsive UI in Depth

The overlay is built to scale gracefully. On a 13-inch laptop in a coffee shop, panels collapse into a single rail on the right edge. On a triple-monitor battlestation, they spread into freestanding widgets you can pin anywhere.

- **Adaptive grid** — the layout reflows rather than crops.
- **DPI-aware rendering** — crisp on high-density displays.
- **Windowed, borderless, and fullscreen compatible**.
- **Low-overhead rendering loop** — designed not to compete with the game for frames.

## 🚀 Getting Started

No arcane rituals. No dependency gymnastics. Limbus Ledger is designed to be lifted and placed.

1. Retrieve the current release package from the maintainer's distribution point.
2. Extract it to a folder you will remember — the City rewards organization.
3. Launch the companion executable alongside Limbus Company.
4. Confirm the overlay attaches to the active game window.
5. Open the **Presets** panel and pick a starting theme.
6. Optionally import a language pack from the locales folder.

The first launch walks you through a short tour of the panels. Skip it if you prefer to explore blind — the fog is patient.

## 🛠️ Configuration

Configuration lives in a single human-readable file. Nothing is obfuscated. Nothing is hidden.

- **Theme selection** — pick from Kizar, Molar, Wuthering, or Blade Lineage.
- **Stat panel placement** — dock left, right, top, or float free.
- **Guardrail sensitivity** — from gentle nudge to firm warning.
- **Hotkeys** — remap everything, including the panic-hide key.
- **Log verbosity** — quiet by default, chatty when you need to debug.

Every change is written on exit and reloaded on launch. Portable mode keeps the config next to the executable.

## 🙋 Frequently Asked Questions

**Is this for solo play only?**  
Yes. Every feature is tuned for a single-player expedition. Group scenarios are outside the current scope.

**Will it work on my older machine?**  
The overlay is deliberately lightweight. If Limbus Company runs, the companion should run beside it.

**Can I contribute a translation?**  
Absolutely. Language packs are plain resources, and contributions are welcomed with clear credit.

**Does it need an internet connection?**  
Only for updates and community lookups. Core features work offline.

**Is my progress at risk?**  
No. Limbus Ledger reads and displays; it does not write into your save data.

**Why the Kizar theme?**  
Because sharp red and black just feels right beside the City skyline.
